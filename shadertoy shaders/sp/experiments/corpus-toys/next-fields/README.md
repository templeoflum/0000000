Three source-specific build scripts only write this folder; provenance JSON records the actual source mirror hashes (canonical/mirror equality was audited earlier). Café Wall: Offset maps0–50% tile width; Mortar maps0–14px (Home7). Preserves width88/height60 tiles, grayscale20/235/128 and perfectly horizontal mortar. Full Field extends the source board across the frame; omits border/UI. Alignment and no-mortar are deliberate proof states, not broken output.

Fraser: Twist maps0–45deg off tangent. Five independent closed rings remain at radii70/120/170/220/270, with source two-tone26×9 bars and42px checkerboard. Trace controls a dashed true-circle overlay at radius220. Uses three nearest candidate bars per ring (15 total), retaining bar center geometry without evaluating all bars per pixel. No actual spiral path is introduced. The Field background fills frame; ring geometry remains centered and aspect-correct.

Hering: Lines maps rounded12–180 spokes (Home120). Keep this density control stationary in Open to avoid discrete popping. Fan varies contextual opacity; target lines never bend, at fixed x±150 and y±230, width5 with rounded ends. Source fan radius900 retained. Full opaque paper background. Fan0 reveals only the straight parallel targets.

All geometry uses explicit scalar distances/edge calculations, avoiding the Wire rectangle expression failure seen in Barberpole. Source-relative units scale to the short frame dimension. No independent animation clock or new modulation architecture. Automatic modulation of proof controls deliberately changes the illusion context; it is not proof that all settings retain perceptual strength.

Validation: all three glslang compilations passed and actual offscreen OpenGL rendered Home/proof pairs at480×320 (Fraser480×480). Each proof changes real pixels; counts and shader hashes in evidence/validation.json. Home samples and combined contact sheet visually inspected. This establishes source output, not native Wire/Arena acceptance, subjective illusion strength, frame rate or smoothness. No installed/runtime/shared engine changes.
