## Surface updates

- Content hashes identify the exact served HTML, eliminating the read/stat version race. The watcher checks file metadata every two seconds and hashes only on change.
- Restore waits for a populated catalog, checks composition epoch, restores A/B, navigation memory, search and mixer bank, and clamps bank bounds.
- Numeric and action mappings validate composition, target identity/scope and parameter name/type/range. Changed contracts drop mappings.
- Reload needs fresh connected/disarmed state, no pending arm, learn, gamepad grab, pointer, queued edit, dialog or focused input, and three seconds idle. MIDI counts as activity.
- Server must explicitly approve the reload. Its two-second lease prevents arming during the reload, including an arm command already awaiting its process check. Stale replies cannot reload the surface.
- Native MIDI's existing didFinishNavigation callback rescans inputs; source code inspected, native reload not rehearsed. Previously connected browser MIDI requests reconnection after restore; actual permission behavior still needs browser rehearsal.
- Old running backend cannot enable the new update flow. First deployment still needs a controlled backend restart and initial surface refresh. The old open page has no session-save code, so do not assume its current mapping survives that initial bootstrap.

## Generic effect opacity envelope

Both panes expose IN / OUT below every numeric effect Opacity. Separate IN/OUT seconds (0.01–120), Low/High in native units, linear/smooth/ease-in/ease-out curve and progress. Settings changes affect the next trigger; an active segment keeps its trajectory.

Opposite direction starts at the last commanded opacity, without a value jump. Duration scales by remaining distance, using the configured time for a full low-to-high span. Same direction deliberately restarts from the opposite endpoint, including after completion. Endpoint is held. Global Hold pauses elapsed time. Manual edit, Drive, native animation handoff, Return Home, Settle, disarm, clip launch and parameter replacement cancel the relevant envelope. Uses the existing numeric output loop and bridge ownership path.

MIDI Learn → click IN or OUT → press a MIDI note/CC button. Separate mappings can coexist with the existing single numeric CC mapping. Note-off and CC zero release; only positive edges trigger. Repeated held messages do not retrigger. Each action mapping has Clear. Learning consumes the learning event without firing. Same physical binding replaces its prior numeric/action destination. These checks were synthetic; physical hardware has not been tested for the new actions.

New envelope controls show “Engine update required” and remain unavailable on the old backend. No native binary change is required.
