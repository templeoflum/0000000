## Architecture, one paragraph

Shaders stay in Resolume (ISF via Wire, full res). The ratio law (kit `ratio.js`: φ = fract(H·m·r+o))
runs OUTSIDE in Python, 64-bit, phase integrated per slot; heart H integrated from Arena BPM,
1 turn = N bars (default 8). The engine takes over any playing "SP" clip (params `<Slot> Drive` …),
switches the shader's own Drive toggles off, and writes slot values by **parameter id** over one
WebSocket (`/parameter/by-id/{id}`, 240 Hz). Arena's UI reflects every write → the dropdowns are the
config UI and the readout. Config changes (Arena edits, shuffles, drives, reset) **morph** — rate blend,
never a jump (measured). Wire In-nodes are write-only, TD non-commercial caps at 1280 px — both
rejected as hosts for this reason.

## What the surface does (all working as of shutdown)

- **Shuffle matrix** per clip: rows = Global + slots, cols = pattern · timing · motion · range · drive ·
  look; cell/row/col arming; ⚡ SHUFFLE (space); auto every N bars; arm-set chips; undo (20); ⌂ reset to
  home / ★ set home (home.json); morph slider; quick ⚡ bar up top.
- **Layer faders**: click-to-LOCK mouse faders (Y only); bypass; explicit ⌂ set home; per-fader
  touch (abs/rel/catch) × release (hold / →0 / →home) applied to mouse AND pad.
- **PAD**: trackpad as a 4-lane fader bank. Assign a fader to lane 1–4, ⌗ PAD (or L) locks the pad
  (cursor hidden, scroll/gesture eaters attached only while locked, LOCKED pill), Esc releases.
  Fingers from the native probe at 125 Hz; strongest contact per lane.
- **Effect rack**: every effect on every layer + composition, auto-discovered; envelope → Opacity;
  modes latch / momentary / one-shot (FLASH to full, spring back); attack/release; quantize to bars;
  bypass-at-0; key-learn per effect (fx.json). Adopts current state on start (never writes on discovery).
