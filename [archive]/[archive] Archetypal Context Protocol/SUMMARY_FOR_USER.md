## 🛠️ Template Structure

Each archetype entry uses this JSON structure:

### Core Metadata
- `SchemaVersion`: "1.1-ter"
- `ArchetypeName`: Main name
- `SystemOfOrigin`: System code (e.g., "GR", "EG")
- `CulturalLineage`: Array of origins
- `CommonAliases`: Alternative names

### 10 Main Sections

1. **SymbolicEssence** - Core function, domain, correspondences
2. **NarrativeRoles** - Story functions, complementary/shadow forms
3. **PsychologicalMapping** - Traits, typologies, variants
4. **CulturalContext** - Origins, appearances, evolution
5. **SymbolicRepresentation** - Imagery, glyphs, artistic examples
6. **MetaIntegration** - Cross-system links, semantic tags
7. **SyncreticMapping** - Equivalent archetypes across systems
8. **FacetRegistry** - Sub-facets with weights
