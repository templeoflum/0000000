## Abstract

The Telescope Effect refers to the perceptual paradox whereby objects viewed through magnifying optical instruments such as telescopes or binoculars appear simultaneously closer in depth yet smaller in perceived size than expected, violating the normal coupling between distance and size perception. When observers view a distant object through a telescope, the magnified retinal image provides strong cues that the object is nearby, triggering depth perception mechanisms that signal reduced distance. However, because the object's magnified angular size may still be smaller than anticipated for an object at close range, or because conflicting depth cues indicate the object's true far distance, the visual system experiences a conflict between size and distance information. This conflict can result in the paradoxical perception that the object is both closer and smaller than when viewed with the naked eye. The effect demonstrates the complex interplay between size constancy mechanisms, which normally compensate for viewing distance to maintain stable size perception, and situations where optical magnification disrupts the normal relationships between retinal image size, binocular disparity, accommodation, and convergence. The phenomenon reveals how the visual system integrates multiple depth cues through Bayesian inference and how violations of expected cue correlations can produce anomalous percepts that dissociate the usually coupled dimensions of perceived size and distance.
