# Spline Reference

The score of *Spatium Dimensio*. Seven movements, fixed in order. Each movement is a function with typed signals: Identity (including Shape) → Math vocabulary → Audio → Visual → Voice → Transition. Sound is the temporal substrate; visual is the spatial moment within it; voice speaks from within both. Reference docs read these signals and supply how each option fulfills them.

---

## The Identity signal includes Shape

Identity carries the movement's structural function, felt weight, what arrives, what departs, invariants, flexibility, **and Shape**. Shape specifies the movement's curvature: how it approaches its knot, how it evolves within itself, how it departs toward the next transition.

Shape is a sub-field of Identity (not a separate top-level signal). Every layer that reads Identity automatically reads Shape.

### Shape sub-functions

Shape composes from three sub-functions:

```
Shape = Approach × Within × Departure
```

**Approach** — how the movement enters its knot (six options):
- *Steep rise* — fast entry from low intensity, arriving with momentum
- *Gradual rise* — slow build into the movement's state
- *Level entry* — arrives already at intended state, no transition energy
- *Gradual fall* — slow descent into the movement
- *Steep fall* — sharp descent, intensity dropping fast into the movement
- *Held* — no tangent energy; the movement arrives in stasis

**Within** — how the movement evolves across its duration (seven options):
- *Steady* — holds its intensity across the movement
- *Rising* — builds across the movement
- *Falling* — releases across the movement
- *Peaked* — rises then falls within the movement (climaxes mid-movement)
- *Troughed* — falls then rises (low point mid-movement)
- *Oscillating* — multiple rises and falls within the movement
- *Stepped* — discrete level changes within the movement (not smooth)

**Departure** — how the movement exits toward the next transition (same six options as Approach).

### How Shape relates to continuity grades

Continuity grade at each join is now derivable from Shape:
- **C⁰** — direction mismatch permitted between departure(N) and approach(N+1)
- **C¹** — direction must match (both rising, both falling, both held); magnitude may differ
- **C²** — direction *and* magnitude must match (steep-to-steep, gradual-to-gradual)

Transitions still author the join's content; Shape constrains its smoothness.

## How Other Layers Connect to the Spline

The spline emits typed signals per movement. Reference docs read them in a dependency order: Identity (including Shape) is universal context for all layers; Math vocabulary is the content being encoded; Audio surface is the temporal substrate; Visual surface is the spatial moment within the substrate; Voice speaks from within both.

```
SPLINE (hub)
   ↓ emits typed signals per movement
   ↓
Identity signal (including Shape) ──→ universal input for all layers
   ↓
Content layers:
   Math vocabulary signal ────────→ Math Audio (temporal primitives, first)
                                  → Math Visual (spatial primitives, second)
   Character signal ──────────────→ Character Reference (parallel)
   Object signal ─────────────────→ Object Reference (parallel)
   Motif signal ──────────────────→ Motif Reference (parallel)
   ↓
Audio surface (composes first as temporal substrate):
   Audio signal + Math Audio + Character + Object + Motif outputs
     → Audio Aesthetic
   ↓
Visual surface (composes second, within audio substrate):
   Visual signal + Math Visual + Character + Object + Motif outputs + Audio surface output
     → Medium ↔ Visual World (mutual within visual domain)
   ↓
Voice layer (reads sonic substrate then spatial moment, plus all content):
   Voice signal + all content outputs + Audio surface + Visual surface → Voice Reference
   ↓
Prompt Construction (assembles triplet: image prompt + audio prompt + narrative prompt)
   ↓
Narrative generation (Pass 6 substitution → Pass 7 outline → Pass 8 voice fill; the framework's only in-flow generator pipeline)
   ↓
Transition Reference informs Pass 6 (substitution) and Pass 7 (outline) cross-modally for all three prompts
   ↓
Script Reference (final integration: drafted narrative + image prompts + audio prompts + transition timing into performable document)
   ↓
Presentation Reference (typographical surface: integrates script + apparatus into readable document)
```

Math precedes surface within each domain because math is the content being encoded. Sound precedes vision: audio is the temporal substrate; visual is the spatial moment within it.

**Per-layer inputs:**

- **Math Audio Reference** reads Identity + Math vocabulary signal. Renders eighteen sonic primitives. Output feeds Audio Aesthetic. Composes first within Math (temporal primitives).
- **Math Visual Reference** reads Identity + Math vocabulary signal. Renders eighteen visual primitives. Output feeds Medium and Visual World. Composes second within Math (spatial primitives within temporal substrate).
- **Audio Aesthetic Reference** reads Identity + Audio signal + Math Audio output. Composed of seven sub-functions: tonality, texture, timbre, rhythm, pacing, spatialization, phrasing. Composes first within Surface (temporal substrate).
- **Medium Reference** reads Identity + Visual signal + Math Visual output + Audio surface output. Composed of five sub-functions: substrate, mark-making, surface behavior, edge quality, color behavior. Mutual with Visual World. Composes within audio substrate.
- **Visual World Reference** reads Identity + Visual signal + Math Visual output + Audio surface output. Composed of five sub-functions: palette, light, line, figure, atmosphere. Mutual with Medium. Composes within audio substrate.
- **Transition Reference** specifies the full continuity function for each of the six joins between movements. Reads layer outputs at end of N and requirements at start of N+1.
- **Voice Reference** is the final composition layer. Reads Identity + Voice signal + Math vocabulary + Audio surface + Visual surface. Composed of five sub-functions: register, stance, positioning, configuration, affect.
- **Prompt Construction Reference** assembles all layer outputs into the triplet.

The spline is the hub. Every reference is a library reading typed signals. A realization composes by reading the spline for a movement, rendering math audio then math visual, composing audio surface as temporal substrate, then visual surface within it, then voice from within both.
